(`pilot_docling_chiusura_20260909-160000/scripts/assi.py`), e deve FALLIRE:

Dopo la correzione si esegue contro `assi2.py` e deve passare.

  riproduci_difetti_strumento.py vecchio   -> attesi i fallimenti (difetto presente)
  riproduci_difetti_strumento.py nuovo     -> attesi zero fallimenti

I difetti, entrambi osservati sulle risposte archiviate del 2026-09-09:

  T1  L'etichetta di CLASSE del blocco (`[SENZA CLASSE]`, `CODICE ESISTENTE`)
      viene raccolta come «valore attribuito alla sezione» perche' compare fra
      backtick nella stessa frase. Non essendo nel corpo della sezione diventa
      `valore_non_trovato`, e una affermazione di sezione CORRETTA
      (sezione_dichiarata == sezione_reale) risulta errata.

  T2  Stessa cosa con il nome di una CLASSE dichiarata (`NORMS`, `METHODOLOGY`)
      o con lo stato di archiviazione.

E i due casi di controllo che NON devono regredire:

  T3  una sezione davvero inesistente resta un errore;
  T4  un valore che sta in un'ALTRA sezione resta un errore.
"""

VECCHIO = pathlib.Path(

QUALE = (sys.argv[1] if len(sys.argv) > 1 else "nuovo").lower()
if QUALE == "vecchio":
    sys.path.insert(0, str(VECCHIO))

# Testo indicizzato di prova: due sezioni, valori distinti. Nomi e valori
# estranei ai cataloghi del pilot.
FONTE = """# manuale_sensori_v3.md
## Registro delle mappe
| File | Formato / peso |

## Prassi di reparto

CASI = [
    # (id, risposta, deve_avere_errori, perche')
    ("T1-etichetta-classe-backtick",

def errori(esiti: list[dict]) -> list[dict]:
    """Un esito conta come ERRORE di attribuzione di sezione solo se la sezione
    non esiste o il valore sta altrove. `sezione_esiste_valore_non_isolabile`
    NON e' un errore: e' un'affermazione di sezione corretta e non falsificata."""
    return [e for e in esiti
            if e.get("esito") in ("sezione_inesistente", "valore_in_altra_sezione",
                                  "valore_non_trovato", "fonte_senza_struttura")]


def main() -> int:
    falliti = 0
    print(f"strumento sotto prova: {QUALE.upper()}\n")
    for cid, risposta, attesi_errori, perche in CASI:
        esiti = controlla_sezioni(risposta, FONTE)
        err = errori(esiti)
        ok = bool(err) == attesi_errori
        falliti += not ok
        stato = "ok  " if ok else "FAIL"
        print(f"  {stato} {cid:32} errori={len(err)} (attesi {'>=1' if attesi_errori else '0'})")
        if not ok:
            print(f"       perche': {perche}")
            for e in err:
                print(f"       -> {e}")
    print(f"\n{len(CASI) - falliti}/{len(CASI)} casi superati")
    return 1 if falliti else 0


if __name__ == "__main__":
    raise SystemExit(main())
